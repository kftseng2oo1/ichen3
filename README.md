# 數位易經 · 三數起卦（完整版副本）

輸入三個數字起卦，依問題類別給出卦象、動爻爻辭與白話解讀。

**線上使用**：https://kftseng2oo1.github.io/ichen3/

## 說明
這個 repo 的 `index.html` 與 [gold](https://github.com/kftseng2oo1/gold) **完全相同**，是同一個 App 的副本。功能請見 gold 的 README；之後只需維護其中一個。

## 主要功能
- 三數起卦：前兩數定上下卦，三數相加定動爻
- 問題類別：事業、健康、感情、財運、股市、購物、訴訟、房產，各爻在各類別都有白話建議

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- 純前端、無外部連線
